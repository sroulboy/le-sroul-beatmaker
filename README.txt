LE SROUL — SITE VITRINE POUR VENDRE DES INSTRUMENTALES

CONTENU
- index.html : site responsive, prêt à personnaliser
- audio/ : place tes extraits MP3 dans ce dossier avec les noms beat-01.mp3, beat-02.mp3, beat-03.mp3

À PERSONNALISER AVANT PUBLICATION
1. Remplacer les titres, BPM, tonalités et prix par tes informations réelles.
2. Remplacer remplace-par-ton-email@example.com par ton adresse e-mail.
3. Ajouter tes extraits audio dans le dossier audio.
4. Ajouter un lien de paiement pour chaque licence (Payhip, Gumroad ou Stripe Payment Link) :
   remplace les liens « Acheter / infos » par le lien de paiement correspondant.
5. Ajouter tes conditions de licence et mentions légales adaptées à ton activité.

HÉBERGEMENT GRATUIT
Tu peux publier ce site statique gratuitement avec GitHub Pages. Le site lui-même est gratuit ;
les prestataires de paiement peuvent prendre des frais sur les ventes. Un hébergement gratuit
ne crée pas automatiquement de paiement ni de livraison automatique des fichiers.

Le site est volontairement autonome et n'utilise pas de framework payant.
